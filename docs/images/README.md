How to add real screenshots:
1. Start server and at least one active SUT.
2. Open dashboard pages in browser.
3. Capture actual screenshots for:
   - Overview
   - IRQ Monitor
   - SoftIRQ
   - CPU
   - Network
   - Diagnostics/Sessions
4. Save PNG files in this directory.
5. Reference them from `README.md` and/or `docs/VISUALIZATIONS.md`.

Do not add mock or synthetic screenshots.
